# AutoAccept Electrical

> **Статус: в активной разработке** — реализованы базовые модули извлечения данных и прототип интерфейса. Полный функционал из концепции ещё в работе.

Программный комплекс для автоматизации создания приёмо-сдаточной документации в области электромонтажных работ. Целевая аудитория - инженеры ПТО, производители работ и подрядные организации, оформляющие акты, протоколы и журналы по требованиям **СНиП 3.05.06-85** и **ПУЭ-7**.

Подробное описание продукта и планируемых функций — в [Documents/Питч_AAE.md](Documents/Питч_AAE.md).

---

## Задача проекта

Ручное заполнение актов техготовности, журналов прокладки кабелей, паспортов заземлений и смежных форм отнимает значительную часть рабочего времени. AutoAccept Electrical призван:

- собирать данные из Excel, PDF и изображений;
- заполнять отраслевые шаблоны документов;
- формировать итоговый комплект документации для сдачи заказчику.

---

## Архитектура

Гибридное десктоп-приложение: **WPF (C#)** для интерфейса, **Python** — для парсинга файлов и генерации документов.

```
┌─────────────────────────────────────────────────────────┐
│              Application (WPF, .NET 4.7.2)              │
│  MainWindow · шаблоны · DataGrid · выбор источников     │
└──────────────────────────┬──────────────────────────────┘
                           │ Process + JSON (stdout)
┌──────────────────────────▼──────────────────────────────┐
│                    Python-модули                        │
│  File_extractors/  — PDF, XLSX, DOCX, OCR (Tesseract)     │
│  File_builder/     — сборка итоговых .docx              │
└─────────────────────────────────────────────────────────┘
```

---

## Структура репозитория

| Каталог | Назначение |
|---------|------------|
| `Application/` | Основное WPF-приложение (Visual Studio solution) |
| `Application/templates/` | Шаблоны отображения данных (напр. `OJR_template` — общий журнал работ) |
| `Application/classes/` | Модели, диалоги, конвертер JSON → массивы |
| `File_extractors/` | Python-скрипты извлечения данных из PDF, XLSX; OCR через Tesseract |
| `File_builder/` | Python-скрипты сборки документов (напр. часть 3 ОЖР) |
| `Auxiliary_modules/` | Вспомогательный C#-код запуска Python-процессов |
| `Documents/` | Питч, wireframe, user flow |

## Текущий функционал

### Реализовано

- **WPF-интерфейс** с деревом шаблонов документов (договоры, приказы, акты и др.)
- **Импорт данных из Excel** — `XLSX_extractor.py` → JSON → отображение в таблице
- **Шаблон ОЖР** (`OJR_template`) — формирование таблицы общего журнала работ с обрезкой строк сверху/снизу
- **Извлечение текста из PDF** — `PDF_extractor.py` (PyMuPDF, pdfplumber)
- **OCR изображений в PDF** — Tesseract с предобработкой (OpenCV)
- **Генерация DOCX** — `OJR_part3_builder.py`, `DOCX_table_builder.py`
- **Мост C# ↔ Python** — `launch_and_data_extraction.cs`
